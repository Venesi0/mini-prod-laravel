# Mini environnement de production Laravel

Projet personnel orienté production informatique / DevOps.

## Objectif

Déployer une application Laravel dans une VM Ubuntu Server avec une architecture conteneurisée propre et documentée.

## Stack cible

- Ubuntu Server
- Docker / Docker Compose
- Nginx
- Laravel / PHP-FPM
- PostgreSQL
- Prometheus
- Grafana
- node_exporter

## Finalité

Construire un projet crédible et défendable en entretien pour une alternance en production informatique ou DevOps.

## Phases

1. Préparation de l’hôte Ubuntu et installation Docker
2. Structure du repo et mise en place Git/GitHub
3. Conteneurisation Laravel / Nginx / PostgreSQL
4. Monitoring
5. Documentation d’exploitation
